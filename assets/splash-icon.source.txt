splash-icon.png, android-icon-foreground.png, android-icon-monochrome.png and icon.png
are generated from assets/branding/loci-mark-pixel.png (the approved Loci path mark): nearest-neighbor 4x (5x for icon.png),
recolored to palette ink #1A1C2C (monochrome: black), centered on a 1024 canvas inside the adaptive-icon safe zone.
The background is Sweetie 16 panel #C9D8E1. Nothing is redrawn.

splash-icon.png is different: it is the FIRST FRAME of the opening animation, which draws nothing, so it is a fully
transparent 384 x 448 image (the 4x mark canvas the splash config sizes against). The native splash then shows only its black
#000000 background, the same colour as the JS loading screen, and the logo is written there. It is generated by
`node scripts/generate-splash-icon.js`. Do not edit it by hand.
