android-icon-foreground.png, android-icon-monochrome.png and icon.png are generated by `node scripts/generate-icons.js`
from the mark grid in src/ui/model/mark.ts (the 60 art-pixel mark of the opening screen, derived from the approved Loci
path mark): night text #cfc8dc on transparent (monochrome: black; icon.png on dark violet #4a4160), 5 px per art pixel,
about half the visible icon's height, centred. The adaptive icon background is dark violet #4a4160 (app.json).
Approved in .pi/generated-images/loci-icon-study.html on 2026-10-11. Do not edit them by hand.

splash-icon.png is different: it is the FIRST FRAME of the opening animation, which draws nothing, so it is a fully
transparent 384 x 448 image (the 4x mark canvas the splash config sizes against). The native splash then shows only its black
#000000 background, the same colour as the JS loading screen, and the logo is written there. It is generated by
`node scripts/generate-splash-icon.js`. Do not edit it by hand.
